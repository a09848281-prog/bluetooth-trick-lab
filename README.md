# Bluetooth & Wi-Fi Explorer (Android APK)

GitHub ActionsでAndroid向けDebug APKをビルドする、Bluetooth LE・Wi-Fi・GPSの電波調査アプリです。

## 機能
- BLE広告を受信し、RSSIの複数サンプル・中央値・平均・受信回数を表示
- 送信出力が不明なBLE機器に、仮の距離(m)を表示しない
- Wi-FiのSSID・BSSID・RSSI・周波数を表示
- GPS位置とWi-Fiスキャン結果を組み合わせ、同じBSSIDを複数地点から観測した場合に位置候補エリアを計算
- 現在地とGPS精度を表示

## Wi-Fiルーターの位置推定の使い方
1. AndroidのWi-Fiと位置情報をオンにして、アプリに位置情報権限を許可します。
2. 「Wi-Fiをスキャン」を押します。
3. 同じWi-Fiアクセスポイント（BSSID）を、8m以上離れた複数地点から測定します。
4. 3地点以上のGPS付き観測が集まると、RSSIが強い観測地点を重視した候補中心を表示します。
5. さらに別の地点で測定して、候補が安定するか確認します。

**重要:** この表示は電波強度の傾向から求めた候補エリアであり、ルーターの実座標・住所を保証しません。壁、階数、アンテナの向き、送信出力、反射、GPS誤差、BSSIDのランダム化などでずれます。1地点だけでは位置推定できません。外部のWi-Fi位置データベースにはBSSIDや位置情報を送信しません。

## RSSIと距離
RSSIは受信信号強度(dBm)です。RSSIだけから正確な距離・方向を求めることはできません。このアプリは根拠のない送信出力を仮定せず、未校正の距離を表示しません。

## Androidの制限
- BLEスキャン対象は広告を発信している機器です。接続中のすべての機器を検出するものではありません。
- Wi-Fiスキャン頻度はAndroid OSが制限します。ボタンを連続で押しても新しい結果が得られない場合があります。
- Wi-Fiスキャン結果の取得には位置情報権限と位置情報サービスが必要なAndroidバージョンがあります。
- 位置情報は端末内で観測の分析に使用します。

## APKの作成
1. GitHubリポジトリのActionsを開く。
2. 「Build Android APK」を選び、Run workflowを実行する。
3. 成功した実行を開き、Artifactsの「bluetooth-explorer-debug-apk」をダウンロードする。
4. ZIPを展開し、app-debug.apkをAndroidにインストールする。

これはテスト用Debug APKです。Release配布には署名設定が別途必要です。
