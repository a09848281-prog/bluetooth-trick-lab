# Bluetooth Explorer (Android APK)

GitHub ActionsでAndroid用のデバッグAPKをビルドするBLE探索アプリです。Android StudioやPCでのビルド作業は不要です。

## アプリの機能

- 周囲でBLE広告を発信している機器をスキャン
- 機器名（公開されていない場合は「名称を公開していない機器」）、アドレス、RSSI（dBm）を表示
- RSSIから距離の参考値を計算
- 同じアドレスの検出結果をまとめ、最新RSSIに更新
- 60秒で自動停止
- 画面表示中の前景スキャンのみ

## APKを作る方法（スマートフォンからでも可能）

1. このリポジトリを開く: https://github.com/a09848281-prog/bluetooth-trick-lab
2. 上部の **Actions** を開く。
3. 左側の **Build Android APK** を選ぶ。
4. **Run workflow** を押す。
5. ブランチが **main** になっていることを確認する。
6. 緑色の **Run workflow** ボタンを押す。
7. 実行一覧に新しい実行が追加されるので、完了まで待つ（通常は数分）。
8. 実行結果が緑色のチェックになったら、その実行名を開く。
9. ページ下部の **Artifacts** から **bluetooth-explorer-debug-apk** を押してZIPをダウンロードする。
10. ZIPファイルを展開すると **app-debug.apk** が入っている。

## Androidにインストールする方法

1. AndroidスマートフォンでZIPをダウンロードする。
2. 「Files」「ファイル」などのアプリでダウンロードしたZIPを開き、展開する。
3. 展開したフォルダー内の **app-debug.apk** をタップする。
4. Androidの設定で、必要な場合だけファイルアプリまたはブラウザに対して「不明なアプリのインストール」を一時的に許可する。
5. もう一度 **app-debug.apk** をタップし、インストールを実行する。
6. インストール後は、「不明なアプリのインストール」の許可をオフに戻す。
7. アプリ一覧から **Bluetooth Explorer** を開き、Bluetoothの使用許可を与える。
8. Bluetoothをオンにし、「周囲のBLE機器を探索」を押す。

## ビルドについて

- mainブランチの対象ファイルを更新すると自動でビルドします。
- Actions画面から手動ビルドもできます。
- 成功したビルドは **bluetooth-explorer-debug-apk** というArtifactとして14日間保存されます。
- これはテスト用のDebug APKです。一般配布用のRelease APKには別途署名設定が必要です。

## 注意事項と制限

- BLE広告を発信している機器だけが対象です。Bluetooth機器すべてが表示されるわけではありません。
- イヤホンなどは広告を出していない、または名前を公開していない場合があります。
- RSSIから計算した距離は目安です。壁・人体・端末の向き・送信出力などで大きく変わります。
- RSSIだけでは機器の方向や正確な位置は分かりません。
- Android 12以降では「付近のデバイス」権限、Android 11以前では位置情報権限が必要です。
- Androidの機種やOSによって、スキャンに必要な設定や表示が異なる場合があります。
