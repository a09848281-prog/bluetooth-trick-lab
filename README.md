# Wireless Intelligence Explorer (Android APK)

Android 13以降を中心に、Bluetooth LE・Wi-Fi・GPS・端末センサーを組み合わせて無線環境を調査するAndroidアプリです。GitHub ActionsでDebug APKをビルドできます。

## 主な機能

### Bluetooth LE
- BLE広告を120秒間スキャンし、機器ごとに最大60件のRSSIサンプルを記録
- RSSI中央値・平均・標準偏差・サンプル数を表示
- RSSIの時間変化から接近/離脱の可能性を表示（距離や方向の断定ではありません）
- 機器ごとに実測距離を登録する校正機能
- 3つ以上の異なる距離で校正し、回帰モデルのR²が0.70以上の場合だけ参考距離を表示
- 校正がない場合やモデル品質が低い場合は距離を表示しない

### Wi-Fi
- SSID・BSSID・RSSI・周波数・チャンネル・暗号化情報を表示
- GPS精度25m以内かつ位置情報が30秒以内の場合だけ観測地点を保存
- 同一BSSIDの8m以内の観測をまとめ、異なる地点の電波傾向を比較
- 最も強かった観測地点と観測範囲を表示
- Wi-Fi測定地点は端末内に保存し、CSV出力可能

### Androidセンサー・端末診断
- GPS位置・精度・更新経過時間を表示
- 加速度・ジャイロ・回転ベクトル・歩数検出センサーの搭載状況を診断
- 回転ベクトルが使える端末では方位を表示
- BLE・Wi-Fi・GPS・Wi-Fi RTT・UWBの端末機能を診断
- Android 13ではAndroid 16のRangingManagerや標準Bluetooth Channel Sounding APIを前提にしません

### データ管理
- Wi-Fi観測履歴とBluetooth校正データを端末内のアプリ領域に保存
- Bluetooth/Wi-Fiの測定値をCSVに出力
- 外部Wi-Fi位置データベースへBSSIDや位置情報を送信しません

## 精度についての重要な注意

- RSSIは受信電波強度であり、単独では正確な距離や方向を測れません。
- Bluetooth校正距離は、登録した環境・端末・機器に依存する参考推定です。壁、人体、アンテナ方向、送信出力、反射などで誤差が生じます。
- Wi-Fiの最強観測地点はルーターの設置場所とは限りません。壁・階数・反射・GPS誤差の影響があるため、アプリはルーターの実座標を断定しません。
- GPS精度の数値はOSが示す推定精度であり、実際の誤差を完全に保証するものではありません。
- Wi-Fiスキャン頻度はAndroid OSにより制限されます。アプリでは連続スキャンを避けるため30秒の間隔を設けています。
- BLEスキャン対象は広告を発信している機器です。すべてのBluetooth機器が検出されるわけではありません。
- UWB、Wi-Fi RTT、Bluetooth Channel Soundingは端末・無線チップ・相手機器の対応が必要です。OSのAPIが存在するだけでは利用できません。

## 使い方

1. AndroidのBluetooth・Wi-Fi・位置情報をオンにします。
2. アプリに「付近のデバイス」と位置情報の権限を許可します。
3. Bluetooth探索を開始すると、検出機器ごとのRSSI分析が表示されます。
4. 機器をタップして校正対象に選び、実測距離を登録します。異なる距離で3点以上測定してください。
5. Wi-Fiスキャンを行い、同じBSSIDを複数地点で測定します。
6. 端末能力診断で、実機に搭載されているセンサーや無線機能を確認します。
7. 必要に応じてCSV出力します。

## APKのダウンロード

1. GitHubリポジトリのActionsを開きます。
2. 「Build Android APK」を選択します。
3. 最新の成功した実行を開きます。
4. Artifactsの `bluetooth-explorer-debug-apk` をダウンロードします。
5. ZIPを展開し、`app-debug.apk` をAndroid端末に移してインストールします。

Debug APKはテスト用です。一般配布用Release APKには別途署名設定が必要です。
